### 1.1 Create ReportRepository interface

**New file:** `lib/features/report/domain/repositories/report_repository.dart`

```dart
import 'package:promsell_pos_ce/features/product/domain/entities/product.dart';
import 'package:promsell_pos_ce/features/sale/domain/entities/sale.dart';

abstract class ReportRepository {
  Stream<List<Sale>> watchSales({DateTime? from, DateTime? to});
  Future<List<Sale>> getSales({DateTime? from, DateTime? to});
  Future<Map<String, Product>> getProductCostLookup(List<String> productIds);
}
```

**Rationale:** Single abstraction for report data needs. `getProductCostLookup` accepts productIds (Phase 3 performance fix — fetch only needed products, not whole catalog).

### 1.2 Create ReportRepositoryImpl

**New file:** `lib/features/report/data/repositories/report_repository_impl.dart`

```dart
@LazySingleton(as: ReportRepository)
class ReportRepositoryImpl implements ReportRepository {
  const ReportRepositoryImpl(this._saleRepo, this._productRepo);
  final SaleRepository _saleRepo;
  final ProductRepository _productRepo;

  @override
  Stream<List<Sale>> watchSales({DateTime? from, DateTime? to}) =>
      _saleRepo.watchSales(from: from, to: to);

  @override
  Future<List<Sale>> getSales({DateTime? from, DateTime? to}) =>
      _saleRepo.getSales(from: from, to: to);

  @override
  Future<Map<String, Product>> getProductCostLookup(List<String> productIds) async {
    // Phase 3: fetch only needed products by id
    final products = <String, Product>{};
    for (final id in productIds.toSet()) {
      final p = await _productRepo.getProductById(id);
      if (p != null) products[id] = p;
    }
    return products;
  }
}
```

**Note:** `getProductById` exists in `ProductRepository` (line 10). For large catalogs, consider adding `getProductsByIds` batch method to `ProductRepository` later — but for now, per-id fetch is acceptable since report periods typically have limited distinct products.

### 3.1 Cache TTL

**File:** `lib/features/report/presentation/cubit/report_cubit.dart`

Change `_cache` from `Map<String, ReportData>` to `Map<String, _CacheEntry>`:

```dart
class _CacheEntry {
  const _CacheEntry(this.data, this.cachedAt);
  final ReportData data;
  final DateTime cachedAt;

  static const ttl = Duration(minutes: 5);

  bool get isStale => DateTime.now().difference(cachedAt) > ttl;
}
```

**Update `_changeDateRangeNow`:**

## Risk Mitigation

| Risk | Mitigation |
|------|------------|
| DI codegen breaks | Run `build_runner` after each annotation change |

| UI regression from decomposition | Golden tests in Phase 4 catch visual changes |
| Performance regression from per-id fetch | Benchmark with `test/performance/db_benchmark_test.dart` |
| Cache TTL too aggressive | Make TTL configurable, default 5 min |
